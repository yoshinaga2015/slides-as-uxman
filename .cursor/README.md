## `.cursor/` について

このフォルダは、このリポジトリで Cursor / エージェントを使う際の **共通ルール・共通Skills** を置くためのものです。

### 追跡（コミット）するもの

- `AGENTS.md`: プロジェクト共通の運用ルール（文体、スライド規約など）
- `*/SKILL.md`: このリポジトリ向けに定義した Skills

### 追跡しないもの

- 個人環境依存・キャッシュ・状態など、共有に向かないもの
- 秘匿情報が混入しうるルール類（例: `.cursor/rules/`）

`.gitignore` で `.cursor/` は原則無視し、上記の共有対象だけを例外として追跡する運用にしています。
特に `.cursor/rules/` は、秘匿情報を入れたくなる可能性があるため **リポジトリでは追跡しません**（各自ローカルで管理してください）。
